it here, and treat it as the authority rather than this page:

**https://github.com/albertoarena/laravel-truss/blob/main/TRADEMARK.md**

This page records only what is specific to this package. Where the two disagree,
the upstream policy is the one that counts.

Filament Truss is free software under the [MIT licence](LICENSE). Nothing on this
page takes away any right that licence gives you over the code. As there, the
licence covers the source; it does not grant any right to the project's name or
brand.

## The Truss name here

The names **Laravel Truss** and **Truss**, used for database structure tooling,
belong to the Laravel Truss project. **This package is an official companion to
it, by the same author**, which is why it carries the name.

The upstream policy already allows anyone to publish a package extending Laravel
Truss when the name reads as an add-on rather than as the project itself. This is
one of those, and the permission it would otherwise need is not in question here.

If you are naming a package of your own, read the upstream policy rather than
copying what this one does.

## A note about "Filament"

**"Filament" is a trademark of its owners and is not covered by this policy, nor
by the upstream one.** This package uses the name under the community convention
for Filament plugins, which prefix the package name with `filament-`.

**This plugin is not official, endorsed, approved, certified, or affiliated with
the Filament project.** It is a third-party package that adds a page to a Filament
panel. If you are naming something of your own, check Filament's own guidance as
well as this page.
